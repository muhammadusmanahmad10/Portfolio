UL Random Access & PRACH for ATG

PRACH is the one place where ATG’s combination of 100+ km cell radius and 500+ kt aircraft speed stretches 3GPP defaults to their edges. Preamble format, Ncs / zero-correlation-zone, cell-radius parameter and the high-speed (restricted) set all interact — a terrestrial default lifted into ATG is a sure path to MAC-RA failures that look like UL coverage problems but are really PRACH-config problems.

Preamble format — the time budget

  • Format 0 — 1 subframe (1 ms), ~14 km max cell radius. The terrestrial default.
  • Format 1 — 2 subframes, ~77 km.
  • Format 2 — 2 subframes with repetition, ~29 km.
  • Format 3 — 3 subframes, ~100 km. This is the ATG baseline because of the 100+ km inter-site.

The preamble must be long enough that even from the far edge of the cell, the signal reaches the eNB and the detection correlator can catch it within the receive window. A too-short format at 100 km means preambles miss the detection window entirely — the UE tries and times out with MAC-RA.

Ncs / zero-correlation-zone — separating preambles across round-trip time

  • Zadoff–Chu sequences have the property that cyclic shifts of the same root are mutually orthogonal — so one root sequence can carry many “virtual preambles”.
  • Ncs (cyclic shift) defines the spacing between those virtual preambles in the time-domain — equivalently, the maximum round-trip delay you can tolerate before shifted preambles bleed into each other.
  • Zero-correlation-zone (ZCZ) = Ncs · Ts — the delay window the cell is sized for.
  • Too-small Ncs at 100 km round-trip means preambles alias, detection collapses, MAC-RA fails.
  • Too-large Ncs wastes preamble codes (fewer virtual preambles per root), forcing more root-sequence rotations and risking root collisions with neighbour cells.

Cell-radius parameter — what to tell the eNB

  • The cell-radius / coverage config is the OAM knob that tells the eNB what round-trip delay to plan for — it feeds Ncs selection, timing-advance range, and detection-window placement.
  • On ATG, cell radius must be set honestly — 100+ km, not the terrestrial 30 km default.
  • A mismatched cell radius is the single most common root cause of “UE can’t PRACH to that cell” stories on long-range sites.

High-speed / restricted cyclic-shift set — Doppler

Zadoff–Chu sequences lose their ideal auto-correlation under Doppler shift. At ATG speeds (~500 kt = ~260 m/s, which at 800 MHz is ~700 Hz of Doppler), a PRACH preamble sent on one cyclic shift can correlate with a neighbouring shift at the eNB — preambles alias.

  • The high-speed flag (prach-ConfigIndex → HighSpeedFlag) tells the eNB to use the restricted cyclic-shift set, which skips the vulnerable shifts and avoids the Doppler-induced aliasing.
  • With HighSpeedFlag off at ATG speeds, preamble detection becomes unreliable at high aircraft speeds — MAC-RA failures that only appear in cruise, not in lab tests.

How misconfig cascades into MAC-RA RLFs

Trigger
UE attempts random access on a target cell during RRC re-establishment after a handover or RLF.
Observed
MAC-RA attempts increment, no RAR received within RA-response-window; UE retries up to preambleTransMax; MAC-RA cause code emitted, RRC re-establishment never completes, T311 expires, UE drops to full setup.
Typical root cause
One of: (a) PRACH format too short for 100 km propagation, (b) Ncs too small so preambles alias at long RTT, (c) cell-radius parameter set to terrestrial default, (d) HighSpeedFlag off at cruise speed, (e) PRACH placement in UL bandwidth colliding with PUCCH SRS.
Diagnostic
Reproduce in the lab with aircard + long-delay channel emulator; verify eNB UL RSSI shows the preamble arriving; walk Ncs / format / radius in the config until MAC-RA succeeds.

Pitfalls I stay aware of

  • Lifting a terrestrial PRACH config into ATG. Cell radius, format and Ncs all have to be re-chosen.
  • Leaving HighSpeedFlag off. Works in lab; fails in cruise.
  • Chasing a UL coverage problem when the symptom is actually a PRACH detection failure.

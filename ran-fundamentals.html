5G RAN Fundamentals — Reference Sheet

A single-page reference for the foundational RAN concepts every senior 5G engineer should be able to discuss cold — radio measurements, modulation & coding, channel feedback, mobility events, idle-mode reselection, broadcast information (MIB/SIBs), bearers (SRBs/DRBs), and the platform terms (eXN, BookBBU, MORAN/MOCN, RedCap, ENDC) that come up in real deployments.

Radio measurements — what each tells you

QuantityWhat it measuresWhere I use it
RSRP (Reference Signal Received Power)Average power of the SSB / CSI-RS reference symbols. Coverage indicator.Cell selection, A-events, coverage tuning.
RSRQ (Reference Signal Received Quality)= N × RSRP / RSSI. Reflects load & interference, not pure power.Quality-driven mobility, congestion sensing.
SINR (Signal-to-Interference-plus-Noise Ratio)The actual usable signal margin over interference + noise. Drives MCS.Throughput ceiling, link adaptation, MCS selection.
RSSITotal received wideband power (signal + interference + noise).Used inside RSRQ; not a quality metric by itself.
💡Rule of thumb: good RSRP can still mean bad SINR (high interference). When throughput is poor with strong RSRP, look at SINR first.

Modulation, coding & link adaptation

ConceptWhat it is
QPSK / 16-QAM / 64-QAM / 256-QAM (and NR's 1024-QAM)Modulation orders. Higher = more bits per symbol = higher throughput, but needs better SINR.
MCS (Modulation & Coding Scheme)An index that picks both modulation and code rate. The scheduler selects MCS per UE based on the reported channel quality.
BLER (Block Error Rate)Fraction of transport blocks failing first transmission. The scheduler targets ~10% BLER for initial transmissions; HARQ retransmissions clean the rest.
CQI (Channel Quality Indicator)UE-reported quality index (0–15) telling the gNB which MCS will hit the BLER target. Higher CQI ⇒ higher MCS.
RI (Rank Indicator)How many spatial layers the channel can support (1–4 typically, up to 8). Drives MIMO rank.
PMI (Precoding Matrix Indicator)UE recommends a precoder from a codebook — closed-loop MIMO precoding.

Loop in practice: UE reports CQI/RI/PMI → gNB picks MCS & precoder → transmits → UE acks/nacks via HARQ → gNB adjusts target. A clamped MCS or low RI almost always points to SINR / interference / antenna config, not transport.

Connected-mode mobility events (NR/LTE)

EventTriggerUse
A1Serving becomes better than thresholdStop inter-freq measurements when serving is healthy
A2Serving becomes worse than thresholdStart inter-freq / inter-RAT measurements
A3Neighbour becomes offset better than servingMost common intra-frequency handover trigger
A4Neighbour becomes better than absolute thresholdInter-frequency handover (no comparison to serving)
A5Serving worse than T1 AND neighbour better than T2Coverage-driven inter-frequency handover
B1 / B2Inter-RAT variants of A4 / A5Handover/redirect to other RAT (e.g. LTE)
💡Time-to-Trigger (TTT) + hysteresis + per-cell offset (CIO) are the three knobs that decide how a measurement crosses an event boundary. Too aggressive ⇒ ping-pong; too lazy ⇒ call drops at cell edge. Tuning these is the heart of mobility optimization (see RF optimization).

Idle-mode mobility — IMCR & redirect-with-release

MechanismWhat it does
IMCR (Idle Mode Cell Reselection)While the UE is in RRC-Idle (no active session), it re-selects cells based on broadcast SIB-driven reselection rules — cell-ranking (R-criterion), priority-based inter-frequency/inter-RAT reselection, S-criteria (Srxlev/Squal), and Treselection timers. The UE never tells the network it moved — it just reads SIB1 of the new cell.
Redirect-with-ReleaseIn RRC-Connected, the source releases the UE with RRCRelease + redirectedCarrierInfo pointing the UE to a target carrier/RAT. Faster than a full handover when service continuity isn't required — common for IRAT 5G→4G when VoNR isn't available and the call needs VoLTE.
Handover vs RedirectHandover preserves the bearer/session (seamless); redirect drops connected state and re-establishes on the new cell. I use redirect specifically where seamlessness isn't the goal.

Both behaviours were exercised on the femto: IMCR for femto↔femto and femto↔macro idle moves (intra and inter-frequency), and redirect-with-release for IRAT 5G SA → LTE.

Broadcast & signalling — MIB, SIBs, SRBs, DRBs

Broadcast (what the cell tells the UE)

  • MIB (Master Information Block) — carried on PBCH inside the SSB. Includes SFN, sub-carrier spacing of CORESET0, and scheduling info to find SIB1.
  • SIB1 — cell access info (PLMN, TAC, cell-barred), scheduling for other SIBs, common channel config. Required for any UE to camp/attach.
  • Other SIBs (SIB2…SIB14) — radio resource config, inter-/intra-freq reselection, neighbour list, warning messages (SIB6/7/8 for ETWS/CMAS), positioning assistance.

Radio Bearers (how UE traffic is carried)

  • SRB0 — RRC before security (initial setup messages).
  • SRB1 — RRC + piggy-backed NAS, ciphered + integrity-protected after SMC.
  • SRB2 — Lower-priority NAS / RRC, only after SRB1 is up.
  • SRB3 — In NSA (EN-DC) for SCG-side direct RRC.
  • DRBs (Data Radio Bearers) — user-plane bearers; mapped from QoS Flows by SDAP per 5QI/ARP. Each DRB has its own PDCP/RLC config.

This is exactly the territory of the SRB criticalExtension dispute — what's mandatory vs optional in RRCReconfiguration for unchanged SRBs.

HARQ & ARQ — the two-layer retransmission

HARQ (Hybrid ARQ) at MAC is fast, per-process (Stop-and-Wait), with soft combining at PHY — incremental-redundancy retransmissions are combined with the previous attempt to recover the block. ARQ at RLC-AM is slower and reliability-focused — it retransmits whole PDUs based on STATUS reports when HARQ alone couldn't recover. A throughput problem with high HARQ retx usually means RF/MCS; rising RLC retx usually means something more persistent. (Detail in protocol stack.)

Platform terms that come up in real deployments

TermMeaning
MORANMulti-Operator RAN — radio & site shared, separate carriers per operator. Each operator broadcasts its own PLMN/cells.
MOCNMulti-Operator Core Network — a shared carrier broadcasts multiple PLMNs, each PLMN routing to its own core.
ENDC / EN-DCE-UTRAN + NR Dual Connectivity — the NSA mode where LTE is the anchor and NR is added for throughput (SCG).
CA (Carrier Aggregation)Combines a PCell with one or more SCells on the same RAT; multiplies peak throughput.
NR UL/DL decouplingUses a low band for NR uplink while keeping a mid band for downlink — extends uplink coverage where mid-band UL is the limiter.
RedCapReduced-Capability NR (Rel-17) — lower bandwidth, fewer Rx branches, longer battery life. For wearables / industrial IoT.
eXNEnhanced Xn between gNBs (vendor / Rel feature set on top of the base Xn).
BookBBUCompact "book"-form-factor BBU variant used in small / dense deployments.
SA / NSA / HybridStandalone (5G core), Non-Standalone (LTE anchor + NR), and hybrid sites running both modes simultaneously.

Common KPIs in one place

  • Accessibility: RRC setup success ratio, NAS attach / registration success, PDU-session setup success.
  • Retainability: call drop rate, session retainability, RRC re-establishment ratio.
  • Mobility: handover success rate (Xn / NG / IRAT), ping-pong rate, RLF count.
  • Integrity: DL/UL throughput (per-cell, per-UE), latency (control + user plane), packet loss / BLER.
  • Resource: PRB / CPU / memory utilization, active UE count, GTP-U / SCTP traffic volumes.
